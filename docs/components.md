# Slashpresent Components

Copy exact patterns from here before inventing one-off markup.

## Kicker + Shell

```html
<div class="slashpresent-kicker">Section label</div>
<div class="slashpresent-shell">
  <h2>Framed section</h2>
  <p>Lead analysis or supporting copy.</p>
</div>
```

## Stat Row

```html
<div class="slashpresent-stat-row">
  <div class="slashpresent-stat-card">
    <span class="slashpresent-stat-value">42%</span>
    <span class="slashpresent-stat-label">conversion uplift</span>
  </div>
  <div class="slashpresent-stat-card">
    <span class="slashpresent-stat-value">3.2x</span>
    <span class="slashpresent-stat-label">pipeline efficiency</span>
  </div>
</div>
```

## Proof Band

```html
<div class="slashpresent-proof-band">
  <span class="slashpresent-proof"><strong>Why now</strong> cost pressure is rising</span>
  <span class="slashpresent-proof"><strong>Constraint</strong> teams need fewer handoffs</span>
  <span class="slashpresent-proof"><strong>Action</strong> consolidate the workflow</span>
</div>
```

## Comparison Table

```html
<table class="slashpresent-comparison">
  <thead>
    <tr>
      <th>Option</th>
      <th>Speed</th>
      <th>Risk</th>
      <th>Recommendation</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Current flow</td>
      <td>Slow</td>
      <td>High</td>
      <td>Retire</td>
    </tr>
    <tr>
      <td>Slashpresent path</td>
      <td>Fast</td>
      <td>Lower</td>
      <td>Default</td>
    </tr>
  </tbody>
</table>
```
